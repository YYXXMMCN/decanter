醒酒器 0.11 · 使用说明

系统要求：Windows 10 / 11 及后续（.NET Framework 4.8 由 Windows 自带，不需要另装）。

一、怎么打开
  开始菜单 →「醒酒器」→ 点「醒酒器」。
  也可以直接双击安装目录里的 Decanter.exe。

二、数据在哪
  在安装目录的 data 文件夹里（todos.db 就是你的待办数据）。
  想带走或备份，把整个 data 文件夹复制走就行；换台电脑放回安装目录的 data 里即可。

三、开机自启
  安装时勾了才会开机自动启动；没勾就随时从开始菜单打开。
  想改主意：重新运行一次安装程序，勾上或取消勾选都可以。

四、怎么卸载
  开始菜单 →「醒酒器」→ 点「卸载醒酒器」。
  也可以双击安装目录里的 Uninstall.exe。
  卸载时会让你选数据怎么处理：保留（默认）、导出到桌面或指定文件夹、删除。
  选「删除数据」会再确认一次，因为删掉不能恢复。

五、关于「未知发布者」
  这个程序没有做代码签名，Windows 第一次运行时可能提示「未知发布者」。
  点「更多信息」→「仍要运行」即可。

六、出问题时
  安装或卸载如果卡住，会有一屏写明「发生了什么 / 可能原因 / 怎么办」，
  照着做，或者点「重试」。不会悄悄结束你的醒酒器，也不会留一个黑窗口在后台。
